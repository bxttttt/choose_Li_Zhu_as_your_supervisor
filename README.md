# README

首先说明一下我的基本立场。我认为，**如果一个人在接手我的论文之后，能够独立完成后续实验、论文修改、投稿以及其他相关工作，并且后续完全不再需要我的参与，那么由接手者担任第一作者，是可以接受的。** 当时我同意调整作者署名顺序，也是基于这一考虑。由于我的职业规划是转向软件开发，这篇论文对我后续发展的重要程度相对有限。相比继续投入大量时间进行实验、论文修改和投稿，我更希望将有限的时间用于开发项目、技术学习和求职准备。从机会成本的角度来看，对我而言，把时间投入开发项目显然比继续投入这篇论文更有价值。

因此，**真正让我无法接受的，从来不是第一作者署名本身，而是在第一作者已经调整、我也明确希望逐渐退出这项工作的情况下，我依然迟迟无法真正摆脱这篇论文。** 如果署名的调整意味着其他人正式接手这项研究，那么与署名相对应的实验、修改、投稿以及后续推进责任，原则上也应当随之发生转移，而不是只完成作者顺序上的变化，却仍然持续要求原作者承担大量实质性的后续工作，并且态度恶劣：

- **即使我抓紧时间干活，仍然会因为zl、cx的拖延和打扰，迟迟不能真正摆脱这篇论文，导致我的暑假严重缩水，有比较长的一段时间，学也没学到，玩也没玩到**。如果没有这两个人，我的简历上可以多一个项目。
- **即使我干活了，还要被老师用很差的态度对待：本人提供后续实验结果后仍被挑剔没有直接在overloaf里改；会议迟到非常久，甚至可以迟到一小时以上，一点也不尊重别人的时间；没有明确让我干某件事情，就默认我要干这件事情，没主动干活就会生气。**
- **既然选择接手一篇由他人完成大量前期工作的论文，并承担第一作者署名，那么至少应该具备独立理解研究内容、完成后续实验、修改论文并推进投稿的能力。但是在合作中可以发现，新的第一作者显然缺乏独立接手并完成该论文后续工作的能力，非常不负责任。**

即便如此，我依然没有打算公开这件事。
更让我生气的，是——**他们在没有征得我同意的情况下，将那篇论文直接替代毕业设计。**
讽刺的是，在那之前我还没有拉黑他们，他们完全有机会提前沟通。实际情况是，在相关成果被用于毕业设计之前，我并没有得到相应的提前沟通，也没有就这一用途明确表达过同意。

给到各位本科生/研究生/博士生的建议是，假如你毕业了，有成果没中，但也不想管了，可以让别人接手，但是一旦交接完别人还来烦你，就要马上拉黑！不管导师或对方多“有威严”，只要没有实实在在的好处，就要马上拉黑它！

而且，**毕业前那么多时间不管我的论文，快毕业了来问我论文还准备不准备投，是何意味？**

**欢迎各位学弟学妹选择其他导师，当然如果你选择了kwz，后续仍有可能被zl指导，可能要给cx做牛马。**

**也存在这样一种可能，这样的恶心事情属于小概率事件。但是，希望大家不要抱有侥幸心理。**
